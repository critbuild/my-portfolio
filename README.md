# critbuild portfolio

A static, mountain-shadow portfolio inspired by cinematic game landing pages. High-contrast orange (`#ff5a1f`), near-black (`#080808`), and white; oversized sans-serif typography, original monochrome SVG landscapes, and viewport-sized scenes with native CSS motion. No React, client router, canvas, video, or animation library.

## Run

Requires Node.js 22.12 or newer and npm.

```sh
npm ci
npm run dev
```

Run commands from this project directory. Production commands, deployment, and browser verification are documented in [Development and verification](docs/development.md).
